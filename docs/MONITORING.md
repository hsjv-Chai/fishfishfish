# 图形化测试监控

服务器独立运行只读监控服务，浏览器每 5 秒刷新。当前保持影子模式，不会自动启用真实鱼干交易。

## 打开面板

当前本机已建立 SSH 隧道：[测试观测台](http://127.0.0.1:18787)。电脑重启或隧道断开后，在终端运行：

```sh
sh /Users/hsjv/Documents/ChatGPT/fishfishfish/scripts/open-monitor.sh
```

保持终端运行，然后打开 http://127.0.0.1:18787。若提示端口已被占用，先尝试直接打开页面，已有隧道可能仍在运行。不要把服务器 8787 端口开放到公网。

## 观察什么

- 运行总览：交易进程心跳（60 秒过期）、扣费后模拟净值、收益、当前回撤、持仓与待确认订单。
- 影子进度：读取交易进程持久化的连续测试时间。暂停页面刷新不影响服务器机器人。达 14 天后仍需导出验收和人工复核。
- 验收清单：回测、工程测试、影子测试、1 条鱼干验证、24 小时内邮件测试。报告必须匹配策略代码版本。
- 历史回测：开发、验证、封存测试集与四档成交偏差；比较现金、全额 BTC、20% BTC / 80% 现金。风险调整收益列为报告的 daily_sharpe。市场暴露是持有非零 BTC 的时间占比，不是资金占比。
- 事件与告警：最近 100 条事件及每个来源最多 30 条告警记录中的活动告警。筛选成交不会影响交易。

净值图最多约 720 个时间桶，取每桶最后一条实际记录；可能省略桶内极值，不能代替完整风控审计。当前回撤直接用最新净值与记录的历史高点计算。没有发生交易时净值横线和空记录均为正常情况。

## 异常如何识别

心跳超过 60 秒会显示过期；接口连接失败保留最后成功数据并显著提示断开，不把旧数据当成实时健康。看门狗目前没有独立心跳，页面只说明其告警数据库是否可读，不据此断言进程存活。邮件通过表示服务端成功提交过测试邮件；用户已另行确认收件。

## 架构与维护

`monitor/server.py` 使用 Python 标准库，只读 SQLite 事务和证据 JSON；前端无外部依赖。服务复用现有 Python 镜像，不加载交易模块，不挂载 secrets，不提供操作交易或配置的 API。Compose 仅绑定服务器 `127.0.0.1:8787`，本机通过 SSH 转发到 `127.0.0.1:18787`。

仅更新监控：上传 monitor 目录，再在服务器 `/opt/fishfishfish` 执行 `sudo docker compose restart monitor`。不要为更新面板重启 trader。停止监控不会停止策略或邮件告警。

独立测试命令：`python3 -m unittest discover -s tests_monitor -v`。HTTP 测试需要允许监听本机临时端口。
